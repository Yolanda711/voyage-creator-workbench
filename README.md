# Voyage · 关岛旅行达人合作工作台 v18

旅行营销与达人合作流程的交互式作品集原型，覆盖达人筛选、Brief 协作、合作跟进、交付与费用记录，以及日英双语旅行落地页。

- [日本語旅行落地页](./landing-ja.html)
- [English travel landing page](./landing-en.html)

## 核心设计

- 候选筛选：平台、预算、公开资料核验与证据缺口；未知信息保持未知，加入意向不代表签约。
- Brief：11章节、多语言、人工检查与版本关联、反馈记录与凭证要求。
- 交付：逐条内容管理，快速更新负责人、截止日和下一步，审稿批准与发布验收分开。
- 费用：预算、合同应付与实付分开，按币种管理。
- 落地页：目的地、行程、交通、准备清单、FAQ与旅行预算工具。

## 作品边界

这是产品与流程设计原型，不是关岛旅游官方服务或已完成的真实营销项目。达人资料为公开研究及模拟演示，不代表受众、报价或合作意愿已经核实。页面不含实际支付、联系或内容发布操作。

记录仅保存在访问者自己的浏览器 localStorage，没有服务器数据库、跨设备同步或实时多人协作。发布的HTML不携带开发者浏览器里的个人填写记录。浏览器内修改不会写回GitHub。

## GitHub Pages 发布

将本目录文件上传至公开仓库根目录（保留 index.html 和 .nojekyll）。在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，保存。部署成功后的 github.io 页面链接可用于简历。详见 [GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

无需依赖安装或构建。静态页面适用于 GitHub Pages。
